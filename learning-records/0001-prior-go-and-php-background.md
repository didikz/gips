# Prior Go and PHP background established

The learner is a senior PHP developer (10+ years) with prior but dated Go experience: small HTTP API projects built several years ago. They are not a Go beginner — syntax, modules, and basic `net/http` are within reach — but idiomatic patterns (error handling, package design, concurrency, testing culture) need deliberate reinforcement through a real project.

**Evidence:** Stated in mission kickoff; module `github.com/didikz/gips` already initialized with Go 1.27.

**Implications:** Skip Tour-of-Go-style syntax lessons. Start at project skeleton + idiomatic HTTP server. Explain Go on its own terms — do not map concepts to PHP frameworks or ORM/repository patterns.
