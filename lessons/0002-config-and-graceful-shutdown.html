Config & graceful shutdown

~30 min · stdlib only · required before Docker

Why now: Lesson 3 puts this in a container. Containers send SIGTERM on stop — your server must drain in-flight requests, not drop them. Structured logs make production debugging possible.

Replace fmt.Printf with slog

Go 1.21+ ships log/slog — structured, leveled logging in the stdlib. JSON logs parse well in Docker and K8s.

log := slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
    Level: cfg.LogLevel,
}))
slog.SetDefault(log)

log.Info("server listening", "addr", cfg.Addr)

Add LogLevel to config.Config, parsed from LOG_LEVEL env (debug, info, warn, error). Default: info.

Graceful shutdown pattern

Run the server in a goroutine. Main waits for SIGINT or SIGTERM, then calls server.Shutdown(ctx).

errCh := make(chan error, 1)
go func() { errCh <- srv.Run() }()

quit := make(chan os.Signal, 1)
signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)

select {
case sig := <-quit:
    log.Info("shutdown signal received", "signal", sig.String())
case err := <-errCh:
    // handle startup failure
}

ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()
srv.Shutdown(ctx)
