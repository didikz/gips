Docker containerization

~45 min · multi-stage build · compose with Redis

Why now: Lesson 2 added graceful shutdown for SIGTERM — exactly what docker stop sends. Today you package gips as an image and run it with Redis beside it.

Create these 3 files (you write them)

  • Dockerfile — multi-stage build
  • .dockerignore — keep image small
  • docker-compose.yml — gips + redis

Multi-stage Dockerfile — concept

Stage 1 (build): full Go toolchain compiles the binary.
Stage 2 (runtime): copy only the binary — tiny, no compiler, no shell.

Proposed shape (adapt to your repo):

# --- build ---
FROM golang:1.27-alpine AS build
WORKDIR /src
COPY go.mod ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o /gips ./cmd/gips

# --- runtime ---
FROM gcr.io/distroless/static-debian12:nonroot
COPY --from=build /gips /gips
EXPOSE 8080
USER nonroot:nonroot
ENTRYPOINT ["/gips"]

Key flags

  • CGO_ENABLED=0 — pure Go binary, runs in distroless (no libc from CGO)
  • -ldflags="-s -w" — strip debug symbols, smaller binary
  • nonroot user — don't run as root in the container

No go.sum yet?

Your project is stdlib-only — you may only have go.mod. Copy go.mod only, or run go mod tidy locally first to generate go.sum.

HEALTHCHECK + distroless

Distroless has no curl or shell. Options:

  • Lesson 3 (simple): put healthcheck in docker-compose.yml using an HTTP check from the host, or skip until K8s probes (lesson 16)
  • Stretch: swap runtime to distroless/debug-nonroot and use busybox wget in HEALTHCHECK

docker-compose.yml

Proposed shape:

services:
  gips:
    build: .
    ports:
      - "8080:8080"
    environment:
      PORT: "8080"
      LOG_LEVEL: info
      REDIS_ADDR: redis:6379
    volumes:
      - ./data:/data
    depends_on:
      - redis
    stop_grace_period: 15s

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

stop_grace_period: 15s gives your lesson-2 shutdown time to drain before SIGKILL.

REDIS_ADDR is for later lessons — gips ignores it for now, but compose won't need changing in lesson 12.
