Docker & CI/CD

Lessons 3–4 · production deploy path

Why early?

Container + pipeline land right after graceful shutdown — before features pile up. Every later lesson stays deployable: docker compose up and green CI on every push.

Lesson 3 — Containerization

Delivers: multi-stage Dockerfile, .dockerignore, docker-compose.yml (app + Redis).

Multi-stage Dockerfile (target shape)

# build stage
FROM golang:1.27-alpine AS build
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -ldflags="-s -w" -o /gips ./cmd/gips

# runtime stage
FROM gcr.io/distroless/static-debian12:nonroot
COPY --from=build /gips /gips
EXPOSE 8080
USER nonroot:nonroot
ENTRYPOINT ["/gips"]
  • CGO_ENABLED=0 — static binary, works in distroless/scratch.
  • distroless + nonroot — minimal attack surface.
  • HEALTHCHECK — curl/wget against /healthz (add in lesson).
  • Volumes — mount ./data for SQLite + local images in dev.

docker-compose.yml (local dev)

services:
  gips:
    build: .
    ports: ["8080:8080"]
    environment:
      PORT: "8080"
      DATABASE_PATH: /data/gips.db
      REDIS_ADDR: redis:6379
    volumes: ["./data:/data"]
    depends_on: [redis]

  redis:
    image: redis:7-alpine
    ports: ["6379:6379"]

Lesson 4 — GitHub Actions CI/CD

Delivers: .github/workflows/ci.yml — lint, test, build image, push to GHCR on main.

Pipeline stages

TriggerJobSteps
PR + push test go fmt check · go vet · go test ./...
push main docker Build image · push to ghcr.io/<owner>/gips

Workflow sketch

name: CI
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with: { go-version: "1.27" }
      - run: go fmt ./...
      - run: go vet ./...
      - run: go test ./...

  docker:
    if: github.ref == 'refs/heads/main'
    needs: test
    runs-on: ubuntu-latest
    permissions:
      contents: read
      packages: write
    steps:
      - uses: actions/checkout@v4
      - uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - uses: docker/build-push-action@v6
        with:
          push: true
          tags: ghcr.io/${{ github.repository }}:latest
