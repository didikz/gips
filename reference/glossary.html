Glossary

Canonical terms for this workspace. Grows as you learn.

Data access

Store — Package of plain functions that run SQL against *sql.DB. Handlers call store directly.

Cache-aside — Read cache first; on miss load from source, populate cache, return. Used for transformed images in Redis.

Project

GIPS — Go Image Processing Service; the production target modeled on roadmap.sh.

Handler — A function satisfying http.Handler or http.HandlerFunc; the unit of HTTP request handling.

Internal package — Code under internal/ that cannot be imported by other modules.

Go idioms

Effective Go — The style guide we follow for naming, formatting, and program structure.

Accept interfaces, return structs — Depend on small interfaces at call sites; constructors return concrete types.

Explicit error — Errors are values returned alongside results, not thrown exceptions.

Terms are added only after you demonstrate understanding in a lesson or exercise.
