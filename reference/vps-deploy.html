VPS deployment (when ready)

Lesson 18 · optional capstone · no cloud account needed to start lessons 1–17

Plan: Learn on kind (lessons 16–17) on your laptop. Provision an empty VPS later — same Helm chart, different values. No blocker to starting now.

Recommended VPS stack

ChoiceWhy
k3s (single-node K8s) One install command, low RAM (~512MB+ workable), good for learning real K8s without managed EKS/GKE
2 GB+ RAM VPS gips + Redis + k3s system pods; 1 GB is tight
Ubuntu 22.04/24.04 LTS Well-documented k3s path
R2 for images Blob storage off the VPS disk — already in lesson 15

What NOT to do on a small VPS

  • Full kubeadm multi-node — overkill for one service on one box
  • SQLite with replicas > 1 — still one gips pod until Postgres
  • Store all images on VPS disk — use R2; VPS holds metadata + Redis only

Lesson 18 flow (when VPS exists)

# on VPS (as root)
curl -sfL https://get.k3s.io | sh -

# on laptop — copy kubeconfig from VPS
# install helm chart with values-vps.yaml
helm install gips ./deploy/helm/gips \
  -f deploy/helm/gips/values-vps.yaml \
  --set secret.jwtSecret=... \
  --set secret.r2AccessKey=...
